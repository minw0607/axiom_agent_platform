# Live smoke gate

`uv run python evals/gate.py --live` drafts five memos with real models and scores them against the golden answers with the thresholds in [`config/eval_gates.yaml`](../../config/eval_gates.yaml) (suite `golden_live`). The five packages cover the outcomes: decline (pkg-04), refer (pkg-06), concentration (pkg-08), a value exactly on a limit (pkg-11) and the known gap (pkg-21). A run costs about 66k tokens. Mean metrics are also compared with the accepted week 6 baseline ([`golden-live.json`](../results/golden-live.json)) over the same packages.

**[`degraded_drafter.md`](degraded_drafter.md)** is a deliberately degraded drafter prompt for week 8's acceptance test A. It reads like a reasonable simplification: shorter, friendlier, "add citations where helpful". It drops the rules that make a memo checkable: cite every factual claim, use only the given numbers, name every risk flag, and the recommendation rules. `--live --degrade` runs the smoke gate with it in place of the current drafter prompt (in a temporary copy of `prompts/`; the real prompts are untouched), and the gate must fail. A replay can't catch this, because replays return the recorded answers whatever the prompt says, which is why prompt changes need the live gate.

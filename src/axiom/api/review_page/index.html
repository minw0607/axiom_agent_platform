Each person has an access key. It decides what you can do here:

  • Relationship manager requests memos for borrowers.
  • Credit officer reviews a draft and approves, rejects or asks for changes.
  • Auditor reads the record of who did what.

Where do I find a key in this demo?

In a terminal in the project folder, run docker compose logs demo-keys. It prints one key for each role.

If you set your own keys in .env, the lines SUBMITTER_API_KEYS, REVIEWER_API_KEYS and AUDITOR_API_KEYS each look like name:key. Paste only the part after the colon.

This is not your OpenAI or Azure key. That one stays in .env and is used only by the platform.

The key is kept only in this browser tab and is forgotten when you close it.

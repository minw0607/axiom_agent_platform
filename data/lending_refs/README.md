# Lending references

A small set of public lending references that the compliance reviewer checks each draft memo against. GKN indexes every `.md` file here (except this README) as the read-only `lending_refs` collection.

| File | Source | Edition |
|---|---|---|
| [regulation_b.md](regulation_b.md) | 12 CFR part 1002 (eCFR) | Current as of 2026-11-09 |
| [occ_rating_credit_risk.md](occ_rating_credit_risk.md) | OCC Comptroller's Handbook, Rating Credit Risk, pages 21 to 25 | April 2001, updated through 2025 |

[manifest.yaml](manifest.yaml) records each file's source URL, retrieval date, edition, current status and hash. Text is quoted exactly from the primary source. Each paragraph starts with a bracketed locator, such as `[12 CFR 1002.6(b)(9)]`, so a retrieved chunk names the provision it came from.

Findings based on these references are drafting aids for the credit officer, not legal conclusions. The OCC booklet is examiner guidance and is applied by analogy only.
